# FTK Mod Framework 1.4.0

Framework 1.4.0 brings Skyharbor to the main menu: an original 3D fortress above the
clouds, a working airship berth, and a `MODDED EDITION` subtitle. The airship departs
and returns on a smooth two-minute cycle with broad turns, gradual acceleration,
gentle heave and a coordinated gangway and mooring sequence.

The scenery stays behind front-end menus, dialogs and loading transitions. Party
Select retains its native character stage, and gameplay retains its own rendering.
This is visual presentation, not a playable sky campaign. Skyharbor is enabled by
default. To restore the original background, exit the game and set
`EnableSkyharborBackground = false` under `[UI]` in
`BepInEx/config/com.ftkmf.framework.cfg`.

The scene and textures are embedded in the framework DLL and arrive through the
existing updater. Duplicate textures share resources. No extra plugin or content
package is required. Compatible framework 1.3.0 installations are included in the
automatic upgrade range. Existing compatible 1.x packages remain supported.

## Verification and limits

The Release build, production flight continuity and embedded-resource checks,
framework capability/reporting tests, player-mod tests, performance tests,
installer fixtures, Go helper/catalog checks, launcher checks, release-manifest
checks and website build/browser suite pass. The live release check uses the
actual framework DLL in an isolated macOS game copy with both prototype plugins
absent. Framework self-tests report PASS, and the embedded scene loads 276 meshes
with 341,348 vertices. A full flight cycle, front-end menu transitions, loading
into native Party Select, return to title, and the configuration opt-out pass.
A known native audio-focus exception still appears at startup; no Skyharbor
loading or rendering failure occurred. See [Skyharbor](../SKYHARBOR.md) for implementation and configuration.

The verified game assembly remains
`94cab5f9be9633f7f85f6f072e0b5b919c605bbecb3414422f8f008d9b2bc1c8`.
The composition is authored for 16:9. Windows and Linux/Proton gameplay, other
aspect ratios, font fallbacks and online co-op remain unverified. The scene does
not change saves or multiplayer state. Windows launcher availability remains a
preview; Linux arm64 is helper tooling, not a native ARM game port. macOS downloads
are not notarized and may require right-click > Open. Steam may need one restart
to refresh shortcut artwork.
