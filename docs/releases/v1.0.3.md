# FTK Mod Framework 1.0.3

Framework 1.0.3 adds class-owned exploration immunity for Poison and Curse. The
separately versioned [Paladin 1.1.0](https://github.com/jarlbrak/ftk-mod-framework/releases/tag/paladin-v1.1.0)
uses it for Cleansing March. Earlier Paladin packages remain separately versioned.

This release also adds an in-game problem reporting panel. Reports are sent only
after the player chooses Send. The panel can save local drafts and offers a
bounded diagnostic preview. See the [reporting guide](../REPORTING.md) for the
sharing and retention details. The reporter's direct-send route was exercised
in an isolated macOS game and created real GitHub issues. Some draft, input and
platform paths remain unqualified.

The stable updater is configured to offer this release to compatible framework
installations older than 1.0.3 on the verified macOS game build. The updater checks the exact
game assembly fingerprint and active managed-package compatibility before
replacing the framework and helper together. A public end-to-end update remains
unverified. Windows and Linux launcher bundles are provided, but their gameplay
paths and automatic updates are unverified.

An isolated macOS game trial loaded framework 1.0.3 with Paladin 1.1.0. The
Paladin crossed a native Poison tile without gaining Poison and entered a native
Curse tile without gaining a curse. A Hunter control gained Poison and Clumsy on
the same native hazard routes. The [live receipt](../paladin/cleansing-march-live-2026-09-24.json)
records the exact binary hashes and limits. Ordinary walking was observed for
Poison; the Curse trial used native tile entry after a movement command stalled.
The [prerelease game smoke](../paladin/release-smoke-2026-09-24.json) separately
registered all 54 Paladin entries, passed five development self-tests, and
started a native single-player session. It did not repeat hazard entry.
Combat ailment application, naturally spawned hazards, save/resume, online
co-op and Windows/Linux gameplay remain unverified for Cleansing March.

The macOS launcher is not notarized, so Gatekeeper may require right-click >
Open. These assets contain no game assemblies.
