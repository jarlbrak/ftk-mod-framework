# Paladin 1.3.0 native release evidence

These screenshots were captured from the original For The King on macOS using
framework 1.2.0. Exact binary, game and image hashes plus selected native state
observations are recorded in [verification.json](verification.json).

The local starting inventory was expanded to make equipment available for fit
review. Inventory captures establish the shown male idle pose only. They do not
prove acquisition, every skinset, full animation coverage or detached fragments.
The inventory item comparison can show the previously equipped item separately.

The Cellar combat was entered through the native New Game flow. Censure was cast
through native input and applied Armor reduction. Smite's displayed damage stayed
at 3 with the 10-damage Novice hammer against that Armor-only effect. Starting
inventory was a fixture; attack outcomes were native rolls. Full campaign balance
and online co-op remain unverified. These checks do not establish public download
or marketplace installation.

A later natural Censure roll applied -4 Resistance to a Forest Gnoll.
[Smite's bonus preview](release-smite-bonus.png) showed 15 with the same weapon;
the native cast dealt 14 magic damage with zero critical damage and defeated
the target. The matching attacker, victim and proficiency fields are retained
in the verification receipt.
