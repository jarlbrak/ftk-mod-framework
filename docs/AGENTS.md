# Documentation instructions

Read the root `AGENTS.md` first.

- Write for the public repository. Exclude personal paths, private services, internal knowledge IDs,
  raw game data, credentials, and temporary session state.
- Link to canonical guides rather than repeating volatile procedures.
- Mark generated documents and update their source generator instead of hand-editing output.
- Preserve evidence boundaries: build, unit test, offline validation, live observation, platform
  coverage, co-op coverage, lifecycle coverage, and art approval are not interchangeable.
- Check relative links and `git diff --check` after documentation changes.
- Do not use em dashes.
