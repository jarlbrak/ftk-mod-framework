# Fixed-four Kraken input experiment

All five same-session paired scenarios completed mechanically and passed native pose equivalence at unchanged 1e-5 tolerance. Each run retains 241 observations, first/repeated samples and all eligible comparisons. Appearance-contributing frames remain explicitly excluded from whole-controller equivalence; the separately verified appearance endpoint policy is unchanged.

All four whitelisted clips are connected before Animator initialization. No playable replacement occurs during sampling. The damaged A/B comparison has identical native clocks, weights and model matrices, while the prior dynamic two-clip experiment failed. This supports the fixed binding/topology arrangement as the correction for this measured input-source defect; a specific internal Unity cache mechanism is inferred, not directly observed.

Each scenario preserves requests, manifest, full verification report, deployment and Ready observations. First/repeat raw JSON is losslessly gzip compressed; validation.json pins decompressed bytes. Native assets and DLLs are not distributed. Reconstruct manifest paths to decompressed files and matching local native files before replaying the pinned verifier with repository dependencies.

These owned experiments do not establish production source synchronization, adapter lifecycle, attack callbacks, original skin appearance or actual gameplay. No enemy coverage count follows from this numerical result. Earlier failed two-clip evidence remains in the separate archive.
