# Existing Kraken input driver observation

The bounded appearance fixture observed 241 frames without synthesizing driver
nodes. Its independent inspector found six required modern input paths absent
from the old Kraken hierarchy. Only `Root_M` was present; its maximum measured
local/model difference from the modern input was about 1.000000119.

[Inspection](inspection.json) pins the exact request and raw report. Native
initialization, matched clocks/weights and cleanup passed the inspector's checks.
The before/after Ready states and lossless compressed report are preserved.
This rules out assuming that the old rig already exposes the modern driver
hierarchy. It does not establish a production adapter or justify a guessed root
offset correction. Constructed Gloamfin skin validation remains separate.
