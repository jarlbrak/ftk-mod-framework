## Know your versions

Framework and mods have separate release numbers. This site documents **framework 1.2.1**, **Paladin 1.4.0**, **Thief 1.0.0**, and **Possum 1.0.0**. These are published downloads. No unreleased features are presented as available.

## Game and platform

Use the original For The King, not its sequel. Paladin, Thief, and Possum are published for **Windows, macOS, and Linux**, using the same platform-neutral content archives. Native gameplay has been verified on macOS; Windows and Linux gameplay remain unverified. Platform availability does not remove the game-build check: the installed game must match a fingerprint declared by the package. An unrecognized Windows, macOS, or Linux build is still blocked.

## Saves and multiplayer

Online co-op is unverified. Matching versions and mod sets is necessary preparation, not proof of compatibility. Existing-save migration is not a promised feature. Restore a save's original mod set or begin a new run if you change content. Removing a mod does not modify the save to remove that dependency.

## Published versus preview

Published pages describe the immutable catalog packages named above. Future previews must carry a separate **Preview / not published** label and must never replace published stat tables. Selecting the launcher's Preview channel is a separate framework update choice. Keep it out of an ongoing run unless you intend to test that release.
