# Thief

A Speed-based paired-dagger specialist with tactical openings, bows, seven equipment tiers, and three artifact weapons for the original *For The King*.

This is version 1.0.0, a playtest. Requires FTK Mod Framework. Install this package and its dependencies in a Thunderstore-compatible **For The King** profile. Restart the game after installing or removing content. Use either this package or the same mod from the in-game marketplace, not both.

Full combat rules, the tested game build, and remaining gameplay limitations are in the [player guide](https://jarlbrak.github.io/ftk-mod-framework/mods/thief/). Save/resume, online co-op, ordinary acquisition, and balance are not established by the current playtest.
