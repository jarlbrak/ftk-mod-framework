# FTK Mod Framework 1.6.1 (preview)

Framework 1.6.1 fixes two problems found while playing the 1.6.0 preview: the
**Refund movement focus** key ended your turn, and the stuck-turn watchdog wrote
warnings when nothing was stuck. It adds no new tweaks. Everything else in
[1.6.0](https://github.com/jarlbrak/ftk-mod-framework/releases/tag/v1.6.0) applies unchanged.

This is a **preview release**. It is published as a GitHub pre-release, so the
Stable update channel does not install it. Preview-channel installations,
including 1.6.0, receive it; you can also pin `v1.6.1` in **Mods > Updates**.

## Fixes

### Refund movement focus key

- **The default key is now F.** In 1.6.0 the default was **Backspace**, which is
  also the game's **End Turn** key. Pressing it ended your turn, left the focus
  spent, and logged nothing. F is not used by any of the game's controls.
- **A saved Backspace becomes F.** BepInEx wrote the 1.6.0 default into every
  config file, so a saved `Backspace` is treated as the old default. At startup it
  is rewritten to `F`, with one log line.
- **A conflicting key never refunds.** A key that one of the game's controls also
  uses is ignored, and you get one warning in the log. The check now runs when the
  HUD redraws and on every press, not only while refundable pips show, so the
  warning appears even when the game acts on the key first. The refund tooltip
  names the key only when it is usable. Clicking a faded pip still refunds.
- **The refund tooltip is correct from the map.** Moving the pointer onto a faded
  focus pip straight from the map showed the game's "Focus Points" tooltip. It
  now shows "Refund focus".
- **The tweak summary states the rule.** You can take back up to one point per
  move you have left, whenever you are standing still with no path chosen, so a
  refund is offered again after a walk.

The key is `[TweakKeys] RefundMovementFocus` in
`BepInEx/config/com.ftkmf.framework.cfg`, default `F`. `None` turns the key off.

### Stuck-turn watchdog

The `[Diagnostics] StuckTurnWatchdog` warning no longer fires:

- while an encounter's choice menu, such as Fight or Sneak, waits for you;
- while a tutorial popup or the encyclopedia holds the input focus;
- for the host's own acknowledgement. The host acknowledgement check now counts
  only other players, so a single-player run never writes `host-ack-15s`.

The 20 and 90 second thresholds, one line per episode and the ten-line cap are
unchanged. The watchdog still changes nothing in the game and never opens a
report on its own.

## Upgrade notes

- **Refund key.** If your config has `RefundMovementFocus = Backspace`, 1.6.1
  changes it to `F` at startup. The log reads
  `RefundMovementFocus was Backspace, the game's End Turn key and the old default; it is now the default, F.`
  Any other key you chose is kept. As a result, `Backspace` cannot be chosen as
  the refund key, even if you have moved End Turn to another key.
- Stable users stay on 1.5.1 until a later stable release is published.
  Preview-channel installations from 0.1.0 up to 1.6.0 on the verified game build
  are in the automatic update range; other game builds keep their bundled version.
- Tweak choices, Session records and save keys are unchanged from 1.6.0. Make a
  backup before testing a preview.
- Use a full game restart after updating.

## Verification and limits

**Game-free checks.** The Release build and the full game-free matrix pass:
framework, Tweaks, Session record hooks, stuck-turn, reporting, player-mod and
performance tests, installer fixtures, Go helper and catalog checks, launcher and
release-manifest checks, harness tests and the packaging dry run. A build or a
game-free test does not prove in-game behavior.

**Live evidence** comes from one macOS test copy, solo offline, keyboard and
mouse, with a build of these fixes (live batch 6):

- **Migration:** a saved `Backspace` logs the migration line once, and the config
  then reads `F`.
- **F refunds:** a press refunds one point, focus 3 to 4 and action points 6 to 5,
  with one log line. Backspace ends the turn as vanilla does, with no refund and
  nothing logged.
- **Conflicting key:** with `M`, the warning appears once, at the first HUD
  redraw. Eight presses across two turns give no refund and no second warning,
  and a pip click still refunds.
- **Tooltip:** five hovers, from four map points and one neighbouring pip, all
  show "Refund focus" with key F. A full pip still shows the game's "Focus Points".
- **Watchdog:** no `STUCK-TURN` line with the Fight or Sneak menu open for about
  89 s, a turn-start tutorial popup open for about 73 s in single-player, the
  encyclopedia open for 38 s and 39 s, the Market open for 45 s, or across 16
  normal end turns.
- No `SELF-TEST FAIL` and no exception from either change.

Live play of the 1.6.0 preview since its release also confirmed that **Show Taunt
and Petrified status icons** shows the Taunt icon in combat and clears it after,
and that **Refund movement focus** exactly reverses a conversion, is blocked while
a path is set or during a walk, and leaves End Turn working at 0 action points.

**Known limitations:**

- Session tweaks are off in online co-op until the co-op contract ships.
- Open live gates: the watchdog's host acknowledgement check with a real remote
  client; each softlock signature firing live; a vanilla load of a save that
  carries records (#253 L8); a second Find Herb in the same dungeon; the group
  shield icon clearing; the Petrified and Dazed icons; the skip-turn popup fix,
  which only the Scourge triggers; Skip intro on a platform where the intro plays;
  controllers; local multiplayer and online co-op.
- Controllers are not supported for **Refund movement focus** or **One-press
  inventory**.
- Windows and Linux/Proton gameplay is unverified. Windows launcher availability
  remains a preview; Linux arm64 is helper tooling, not a native ARM game port.
  macOS downloads are not notarized and may require right-click > Open. Steam may
  need one restart to refresh shortcut artwork.

**Known issue, not caused by the framework:** on macOS the game can hang when you
quit, inside the game's own sound engine while it unloads its sound banks. A
sample of the hung main thread showed no framework code. Force quit the game if it
does not close.
