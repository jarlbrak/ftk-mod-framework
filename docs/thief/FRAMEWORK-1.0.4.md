# FTK Mod Framework 1.0.4

Adds runtime and marketplace support for the separately installed Thief 1.0.0 playtest: precision weapons, preparation and openings, artifact signatures, equipment modifiers and paired weapon visuals. Existing framework 1.0.3 features are retained.

Managed package previews now survive startup verification. The helper accepts the supported Thief declarations while continuing to reject unsupported fields and invalid assets. Framework and helper must be updated together.

Thief is a separate marketplace download. Single-player macOS registration, native menu and banner presentation, and representative combat have been exercised; detailed evidence and remaining gates are in docs/thief/VALIDATION.md. Balance, combat edge cases, higher-tier and female outfit fit, ordinary acquisition, multiplayer, save/resume, and hot-reload lifecycle remain unqualified. Final mouse usability approval remains with the user.

Windows and Linux launcher/helper artifacts are provided, but their gameplay paths are unverified. macOS downloads are not notarized and may require right-click Open. Automatic updates are limited to the verified macOS game fingerprint. Public update and install results will be recorded separately from local verification.
