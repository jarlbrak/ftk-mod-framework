# Validate spec

1. Read the spec, inherited epic requirements, child work items, linked PRs, code, tests, and docs.
2. Build a requirement-to-implementation-to-proof matrix. Do not treat issue checkboxes as evidence.
3. Run the proportional verification matrix and inspect live evidence for claims that require it.
4. Obtain independent architecture review and route material findings back to implementers.
5. Create focused remediation items for real gaps. Do not weaken requirements to match the code.
6. Mark the spec ready only when every requirement is implemented, evidenced, documented, and no
   blocking child/remediation item remains.
