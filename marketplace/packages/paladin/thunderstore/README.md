# Paladin

A Vitality-based protector for the original *For The King*. Guard protects an ally, Cleansing March prevents new Poison and Curse while exploring, Paladin hammers apply Censure, and equipped Paladin trinkets grant Smite.

Requires FTK Mod Framework. Install this package and its dependencies in a Thunderstore-compatible **For The King** profile. Restart the game after installing or removing content. Use either this package or the same mod from the in-game marketplace, not both.

The game build, gameplay evidence, full ability rules, and item details are documented in the [player guide](https://jarlbrak.github.io/ftk-mod-framework/mods/paladin/).
