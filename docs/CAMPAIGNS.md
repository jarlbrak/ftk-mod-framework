# Campaigns and quests

The campaign API authors multi-stage questlines inside a `GameDefinition`. It is an advanced framework capability; the [Paladin package](../marketplace/packages/paladin/content.json) is the shipped content example and does not contain a campaign. Start with [adventure registration](ADVENTURES.md) and test each custom route before claiming it works in solo play, saves, or co-op.

FTK stores quests as `QuestDefBase` objects in `GameStage.m_Quests`. `Adventures.AddCampaignFromTemplate` clones an installed adventure and configures stages through `CampaignBuilder`. Stage builders add kill, visit, clear-dungeon, encounter, and collect-item quests. `QuestBuilder.BranchTo` defines first-match branch edges; `OnCompleteSetFlag` writes a campaign flag before the next branch resolves. `WithStartStory` and `WithCompleteStory` attach native story popups. Quest IDs must be unique across the campaign, and the last quest of the last stage is the victory target.

The framework validates duplicate IDs, unresolved game references, invalid collect counts, unknown operators, and branches that cannot reach victory. Supported condition comparisons are `eq`, `ne`, `ge`, and `le`; flag mutations are `set` and `add`. Use chained quests for compound conditions. Save state uses quest/stage string keys and campaign flags rather than synthetic enum IDs.

Custom NPC portraits and text belong in the adventure's own mod folder. `Adventures.RegisterUserNpc` registers their name, title, and portrait. Custom objective verbs require a registered `QuestLogicBase` behavior from a behavior DLL; the current [marketplace package contract](MARKETPLACE.md#content-submission) does not distribute behavior DLLs or campaign files. The `[Campaign] EnableCampaignEngine` setting defaults on; when disabled, branch routing and custom verbs do not run, even if the adventure remains selectable.

A save whose campaign mod is missing cannot load until that mod is restored. Branch evaluation and flag writes are designed for host authority, but design and serialization checks are not two-client play evidence. Validate the exact campaign, platform, save/resume path, and co-op route that you intend to support.
