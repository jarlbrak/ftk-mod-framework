# FTK Mod Framework

Initial **Windows** setup for FTK Mod Framework, a content-modding framework for the original *For The King*. Requires the game, Steam, and .NET Framework 4.8.

## Install once, then use the FTK launcher

1. Install this package and its BepInEx dependency in a For The King profile.
2. Start the profile and choose **Set up and open FTK Modded Launcher**.
3. Setup opens the launcher and closes the game. When the game has exited, choose **Play** to finish installation.
4. For future play, open **For The King Modded** from **FTK Mod Framework** in the Windows Start menu. You can also use **Add to Steam / Art** in the launcher.

The launcher manages framework updates. Install and manage content mods through the in-game marketplace. Individual content mods do not need Thunderstore packages.

Your launcher and framework installation live outside the initial manager profile. Deleting this package or profile does not uninstall them. Starting the initial profile again shows setup again. Other mods in that profile are not migrated. Use the FTK launcher for your managed installation.

If setup fails, the game stays open and displays the error. Reinstall this package if its setup files are missing or damaged. On macOS, Linux, or Proton, use the normal platform launcher from the player guide.

The game and its assemblies are not included.
