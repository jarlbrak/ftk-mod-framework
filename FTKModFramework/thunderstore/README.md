# FTK Mod Framework

FTK Mod Framework is a BepInEx 5 plugin for the original *For The King*. It loads curated JSON content packages, including classes, equipment, appearances, enemies, and other supported content.

Install this package in a Thunderstore-compatible **For The King** profile. It depends on the For The King BepInEx pack. The game and its assemblies are not included.

Use one framework distribution channel per profile. Do not install this alongside a second copy from the FTK Mod Framework launcher or a manual installation. Do not install the same content package through both Thunderstore and the in-game marketplace.
