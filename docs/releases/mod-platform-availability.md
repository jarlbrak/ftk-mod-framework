# Published mod platform availability

The author requested publication of all current mods for Windows, macOS, and Linux.
The production catalog now offers Paladin 1.3.0, Thief 1.0.0, and Possum 1.0.0 on
all three platforms. These are platform-neutral declarative content archives; this
publication change updates catalog metadata only. Released ZIP bytes, versions,
manifest identities, hashes, sizes, and framework requirements remain unchanged.

The platform declaration records availability, not completed gameplay validation.
Existing native gameplay evidence is macOS-only. Windows/Linux gameplay, multiplayer,
and the per-mod lifecycle and presentation limits remain unverified as stated in each
listing. This is an author-authorized availability expansion beyond the publishing
guide's usual tested-platform-only policy, not new evidence of platform correctness.

The existing game assembly fingerprint allowlist remains enforced. A Windows or Linux
installation with a different assembly hash is still blocked; obtain and validate that
build before adding its fingerprint. No wildcard, fabricated fingerprint, or runtime
compatibility bypass is introduced. Framework release selection is unchanged.
