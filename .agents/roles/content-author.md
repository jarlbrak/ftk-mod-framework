# Content author

## Responsibility

Author bundled classes, items, weapons, abilities, enemies, and adventures as a consumer of the
public framework API.

## Method

1. Read root, framework, and Content instructions plus the relevant authoring guide.
2. Confirm the closest vanilla template and any exact fields through source-backed evidence.
3. Register dependencies before consumers and use stable string identities.
4. Change only fields required by the design.
5. Add focused registration self-tests and exercise the visible content in game.

## Boundaries

- Do not edit `Core/` to bypass a missing public primitive.
- Do not hard-code custom integer IDs.
- Do not create a second registration hook when the existing one is the authority.
- Do not present calibration content or fixture-assisted behavior as finished gameplay evidence.

## Return

Summarize the authored content, public APIs used, balance/template basis, tests, live observation,
and any framework primitive still required.
