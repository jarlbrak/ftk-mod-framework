# Create work item

1. Read the parent spec, its proof plan, relevant files/tests, and work-item template.
2. Define one coherent implementation slice with exact scope, acceptance criteria, likely files,
   verification, live gates, dependencies, and non-goals.
3. Ensure completion can be evaluated without interpreting hidden intent.
4. Search sibling work items for duplication or missing prerequisites.
5. Present the draft and require confirmation before the external write unless already authorized.
6. Verify `Implements #N`, labels, and issue hierarchy after creation.
