# Slip Away action icon

Original raster icon generated with the built-in imagegen tool for the Thief
class action. The visual follows `docs/thief/ART-DIRECTION.md`: one boot and a
curved escape line, with worn leather, dusty blue, aged brass, and ivory.
No game asset was supplied as a generation input.

`thief-slip-away-source.png` retains the generated RGBA pixels. The package copy
is `marketplace/packages/thief/assets/thief-slip-away-icon.png`. The source is 1254 by 1254 pixels. The package copy was resized to 1024 by
1024 with `sips -Z 1024` to satisfy the framework icon limit. Its alpha channel
is preserved.
The icon's broad boot silhouette and curved arrow were visually inspected in the
generation result. Final native action UI legibility is a live-game gate.

`preview.html` defines 256, 64, and 32 pixel views against a dark background.
The browser tool rejected its local-file URL, so this record does not claim a
completed browser review or a native-size visual pass.

## Generation prompt

Use case: stylized-concept. Create one original square raster game action icon
for 'Slip Away' in the For The King Thief class. Subject: one soft ankle boot
made of warm worn brown leather, a dusty blue folded cuff, a narrow aged-brass
buckle, and dark sole, seen in a dynamic lifted side-three-quarter view with the
toe pointing right. A single thick ivory curved escape stroke sweeps behind the
heel and underneath the boot toward the right, ending in a small arrow point,
visibly separated from the boot. The curved escape line must read clearly at
32px. Style: low-poly faceted game prop, clean broad polygon surfaces, flat
colors with restrained ambient shading, sharply readable silhouette, minimal
small detail; coordinated palette worn leather brown, dusty blue, restrained
brass and ivory. Composition: centered icon silhouette filling 80 percent of
square, whole boot and whole curved arrow visible, generous clean margins.
Genuinely transparent background with clean alpha, no cast shadow beyond the
object, no backdrop, no ground plane, no border, no lettering, no badge, no
watermark, no characters or other props. Native deliverable target 256 by 256
pixels.

The tool returned a larger square PNG than requested. No native resolution
claim follows from the requested prompt size.
