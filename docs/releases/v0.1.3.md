# FTK Mod Framework 0.1.3 early-access preview

Content mods now declare the framework version their author has confirmed. Minor and patch
framework updates within that major remain compatible; a new major needs a new mod release
with an updated manifest declaration.

## For players

Existing content mods need an author-provided manifest declaration before they can load
under this preview. The included Adventure Pack is already paired with the framework.

Installed mods show their framework requirement. Content mods with missing declarations or
incompatible versions remain visible with an explanation and do not load their content or
behavior code. Saved enable preferences are preserved.

The launcher also checks active and pending managed mods and manually installed content
manifests before changing framework versions.
Pinning a version does not bypass compatibility. Independently loaded BepInEx plugins remain
outside the content-manifest checks.

## For mod authors

Add `frameworkVersion` to `manifest.json`, separately from your mod's own `version`:

```json
{
  "modGuid": "com.example.wayfarer",
  "name": "Wayfarer",
  "version": "1.0.0",
  "frameworkVersion": "0.1.3"
}
```

This declaration permits framework `0.1.3` and newer `0.x` releases, including new minor
versions. It does not permit framework `1.0.0`. Test that new major, update the declaration,
and publish a new mod version to confirm support. Published archives retain their bytes.

Marketplace descriptors must match the archive declaration and retain its canonical
same-major `frameworkRange`. See the repository's `docs/MOD-VERSIONING.md` for the full policy.

## Validation

Verified on macOS with compatible, future-major, and undeclared test manifests. Blocked
mods stayed visible and their content and behavior files were not loaded. All 13 content
self-tests passed. A blocked bundled restore retained the installed framework, helper, and
receipt unchanged.

## Updating

**Download the 0.1.3 launcher bundle to get the new manual-mod checks before updates.**
Replace the old launcher files together or point Steam at the new launcher. Updating only
the framework and installed helper does not replace the helper inside an older launcher
bundle.

Choosing **Follow Preview** or pinning **v0.1.3** still updates the runtime compatibility
checks on the next launcher start. New installations should use the platform launcher
archive attached here.

Windows and Linux gameplay remain untested. No copyrighted game assemblies are included.
The community catalog is online and intentionally empty until reviewed mods are published.
