## Framework 1.2.0

Adds equipment-granted combat actions and conditional damage support used by Paladin 1.3.0. Smite follows the equipped trinket, and Censure can create the Resistance opening that strengthens it. Use a full game restart after changing content with these new capabilities. Download the launcher from the [framework release](https://github.com/jarlbrak/ftk-mod-framework/releases/tag/v1.2.0). Framework and mod versions are independent; a new mod release does not replace the framework download.

## Paladin upgrade notes

Moving from 1.2.0 to 1.3.0 requires framework 1.2.0. The new equipment artwork, Censure on all Paladin hammers, and Smite from equipped Paladin trinkets are published. Base Vitality remains 80; the Highward, Mercy, Censure, and Verdict great hammers retain damage values of 32, 34, 34, and 37.

Restart after preparing an upgrade and start a new adventure when changing content. Existing-save migration and long-campaign balance remain unverified. [Read the full Paladin guide](../mods/paladin/).

## Previous versions and future previews

[GitHub release history](https://github.com/jarlbrak/ftk-mod-framework/releases) preserves previous immutable packages. Old versions are not silently replaced with new bytes. This site has no unreleased gameplay preview. Any future preview will be labeled separately from these published packages.
