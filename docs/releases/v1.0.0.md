# FTK Mod Framework 1.0.0

The first stable framework release adds the native Mods menu, managed package
installation and activation, and content APIs used by the Paladin package.
Paladin is distributed as one separately versioned marketplace mod. Its 51
equipment items include original 3D models, with two legendary hammers and a
legendary shield.

Install the new platform launcher bundle to get the matching framework and
helper. Existing 0.1.x framework installations may follow the stable update
channel on the verified macOS game build. Other game fingerprints remain pinned
until they have corresponding game evidence.

The macOS game trial covered native mod management, registration, new-game and
fresh-process resume, Paladin Guard's direct-hit reduction, a controlled custom
loot collection and cross-class equip. Controlled fixtures establish those
specific paths; natural drop frequency, every accessory presentation and full
campaign balance are not established by them. Windows and Linux/Proton gameplay
and online co-op remain unverified. The macOS launcher is not notarized, so
Gatekeeper may require right-click > Open.

No copyrighted game assemblies are included.
