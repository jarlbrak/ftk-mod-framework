# FTK Mod Framework 1.0.1

Version 1.0.1 is the first supported public framework release for the original
*For The King*. It includes the launcher, the native Mods menu, managed mod
installation and activation, and the public content APIs used by the separately
versioned [Paladin 1.0.1](https://github.com/jarlbrak/ftk-mod-framework/releases/tag/paladin-v1.0.1)
package.

This patch removes the old bundled Adventure Pack and its Thief, Innkeeper,
Cutpurse and other development examples. Paladin is the only curated marketplace
package. The release also aligns the helper's save-set fingerprint with the
remaining framework settings and preserves same-major package compatibility.

Install the platform launcher bundle, then use the in-game Mods catalog to
install Paladin. Existing 0.1.x or 1.0.0 framework installations on the
verified macOS game build can follow the stable update channel. Settings and
game saves remain outside the launcher bundle. A save created under a different
framework or enabled mod set may require its exact compatible library.

An isolated, windowed macOS launch of framework 1.0.1 loaded Paladin as the only
enabled mod and registered all 54 package entries without content errors. The
native Party Select showed Paladin on a game-owned human avatar. Earlier
Paladin 1.0.0 trials observed new-game and fresh-process resume, Guard's
direct-hit reduction, and controlled loot collection on another class. The
1.0.1 launch did not repeat combat or save/resume. Natural drop frequency,
every accessory presentation, full campaign balance, Windows/Linux gameplay
and online co-op remain unverified. The macOS launcher is not notarized;
Gatekeeper may require right-click > Open.

The framework release contains no copyrighted game assemblies. Paladin's
archive contains original content and art, with no executable code.
