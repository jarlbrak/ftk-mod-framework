# FTK Mod Framework 0.1.2 early-access preview

Release notes now render Markdown inside **Mods > Updates**. Read them continuously in a
scrollable panel, or expand the reader for more room. The old notes pagination is gone.

## Updating

If you already use the 0.1.1 launcher, select **Follow Preview** in **Mods > Updates** and
launch again. You can also pin **v0.1.2**. Stable followers stay on their installed version
until a stable release is published.

New players can download and extract the archive for their platform, then add its launcher
to Steam as a non-Steam game. Keep the extracted package together.

| Platform | Download | Launcher |
| --- | --- | --- |
| macOS 13+ | `FTKModdedLauncher-macos-universal.zip` | `For The King Modded.app` |
| Windows 10/11 x64 | `FTKModdedLauncher-windows-x64.zip` | `FtkModdedLauncher.exe` |
| Linux x64 / Steam Deck | `FTKModdedLauncher-linux-amd64.tar.gz` | `For The King Modded.sh` |

Users of the original **0.1.0 launcher** still need a one-time launcher bundle upgrade to
use version selection. **Restore bundled** remains available if you try an older version.

## Preview status

Windows and Linux gameplay remain untested. The Windows launcher is cross-built for .NET
Framework 4.8. The Linux arm64 package is helper tooling, not a native ARM game port.
No copyrighted game assemblies are included.
