# FTK Mod Framework 0.1.1 early-access preview

Choose your framework version inside the game. Open **Mods > Updates** to see your running
version, available releases, and patch notes, then choose:

- **Follow Stable** for newer stable releases.
- **Follow Preview** for newer releases, including previews.
- **Pin version** to stay on one exact release until you change it.

Your choice applies on the next launcher Play. Automatic channel changes never silently
downgrade the framework. An explicit older-version choice still needs to pass integrity,
game-build, and managed-mod compatibility checks. Offline launches retain the verified
installed version, and cached release notes remain readable.

## Upgrade or install

Download the archive for your platform, extract it permanently, and add the launcher to
Steam using **Games > Add a Non-Steam Game > Browse**:

| Platform | Archive | Launcher file |
| --- | --- | --- |
| macOS 13+, Intel or Apple Silicon | `FTKModdedLauncher-macos-universal.zip` | `For The King Modded.app` |
| Linux x64 / Steam Deck | `FTKModdedLauncher-linux-amd64.tar.gz` | `For The King Modded.sh` |
| Windows 10/11 x64, .NET Framework 4.8 | `FTKModdedLauncher-windows-x64.zip` | `FtkModdedLauncher.exe` |

**Existing 0.1.0 users need this new launcher bundle once.** Its old startup helper cannot
read version choices. Replace the old launcher files together and launch through the new
bundle. First setup and Steam artwork remain automatic. Keep the package's files together;
Steam may need a restart to refresh artwork. Mac downloads may require right-click > Open.

## Restore after trying an older version

Older releases may not include the version picker. Close the game and choose **Restore
bundled** on Windows, or run **Restore bundled.command** on Mac / **Restore bundled.sh** on
Linux. This restores the version included in your downloaded package and returns updates
to Stable, while preserving installed mods. Normal version switching preserves settings;
Restore bundled reapplies player defaults.

## Validation

Verified on macOS through the Steam launcher: title-screen startup, 13 content self-test
passes, release-note paging, Stable and Preview selections, and saving an exact older release
without replacing the running framework. A real download of published v0.1.0 and Restore
bundled back to v0.1.1 also passed with verified hashes.

## Preview status

Windows is cross-built and checked with installer fixtures; Windows game installation,
SmartScreen, Steam integration, and gameplay remain untested on Windows. Native Linux and
Proton gameplay also need platform testing. The arm64 Linux archive supports helper tooling,
not a native ARM port of the game. The marketplace remains free and its initial community
catalog is empty pending reviewed submissions.

The updater replaces the framework and its paired helper, not BepInEx or the launcher
bootstrap. Manual mod compatibility cannot be fully checked. No copyrighted game assemblies
are included. All release artifacts are covered by `SHA256SUMS`.
