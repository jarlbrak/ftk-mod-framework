# Possum

An original possum appearance for your adventurer, with faceted fur, rounded ears, and a long pink tail. Class abilities, stats, and native equipment remain unchanged.

Requires FTK Mod Framework 1.1.0 or a compatible later 1.x release. Install this package and its dependencies in a Thunderstore-compatible **For The King** profile. Restart the game after installing or removing content. Do not downgrade the framework while using saves with custom races. Use either this package or the same mod from the in-game marketplace, not both.

The [player guide](https://jarlbrak.github.io/ftk-mod-framework/mods/possum/) describes the tested appearance and remaining platform, equipment, and co-op limits.
