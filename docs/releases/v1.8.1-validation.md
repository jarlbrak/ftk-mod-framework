# Framework 1.8.1 validation

## Scope

This patch adds native-color class skill rows to registered weapon tooltips and
aligns the Paladin guide's weapon cards with their in-game wording and order.
Paladin stays at 2.0.1. Its archive, catalog identity, gameplay, acquisition and
minimum framework requirement are unchanged.

## Game-free checks

- Release build passed with seven existing warnings. Plugin and assembly versions
  both report 1.8.1.
- All 45 top-level framework test projects passed, including 116
  CombatProficiencies checks. Installed-game metadata and IL contract checks passed.
- PerfProbe passed 24 tests; helper Go tests and catalog validation passed.
- Installer fixtures passed 27 checks. Windows launcher cross-build,
  LaunchOptions, Unix launcher, release manifest, Thunderstore and shell checks passed.
  Windows-only path normalization checks were skipped on macOS.
- Harness, runtime-test and model-pipeline suites passed. The model pipeline's
  96 explicit skips require ignored local fixtures, capture archives or prior reference data.
- Website build and browser checks passed across 14 pages at desktop and mobile
  sizes, including published equipment cards, navigation, search and filtering.
- Whitespace and tracked-game-assembly guards passed.

## Live game

The 1.8.1 candidate framework was tested in a disposable macOS copy against game
assembly SHA-256 `94cab5f9be9633f7f85f6f072e0b5b919c605bbecb3414422f8f008d9b2bc1c8`.
Pre-commit candidate framework SHA-256: `eb587069b160612ea8cbba8d6c6442916be0cfa47201d27cd0528c490baa0c72`.

Startup reported SELF-TEST PASS for behavior primitives, quest logic construction,
DLL path guards, passive registration and data-content determinism. Intentional
rejected-registration diagnostics came from the self-test fixtures.

All 14 Paladin hammers were supplied through a test-only starting inventory.
Each tooltip displayed `Paladin Skill: Censure` and `Paladin Skill: Smite` once.
The preceding candidate's full front, modifier, skill, perk and set text matched
the website for all 14 weapons. Common, rare and Artifact cards were visually
reviewed for spacing and clipping. No ordinary acquisition claim follows from
this fixture. The disposable deployment was restored after testing.

## Limits

Website artwork, fonts and roll icons are original browser substitutes; the
weapon cards preview no matching armor or armament equipped. No new Windows,
Linux/Proton gameplay, co-op, save lifecycle, animation or balance coverage is
claimed. Cross-building a launcher does not prove native platform execution.
