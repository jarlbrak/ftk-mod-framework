# FTK Mod Framework 1.2.1

Class cards for Guardian and exploration-immunity classes now display compact
skill-name entries, matching native class presentation. Guard's detailed rules
remain in its combat proficiency description. The framework no longer shifts
the native starting-equipment section to accommodate mechanics paragraphs.
Existing native abilities and unregistered classes keep their native presentation.
Custom ability labels remain English-only.

This patch is required by Paladin 1.4.0, which separately reduces its starting
kit to Novice Hammer and Novice Aegis and uses two sentences of class flavor.
Combat mechanics and base stats are unchanged. Install the framework update
before selecting the new Paladin package. Existing compatible 1.x packages
remain supported, and framework 1.2.0 is included in the automatic upgrade range.

the data-content determinism check. The optional full diagnostic suite was off.
