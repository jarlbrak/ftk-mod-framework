# Lore Store Unlocked

Every Lore Store entry reads as purchased while this mod is installed. It does not write purchases to your local profile or Steam, so removing it restores your own unlocks.

Requires FTK Mod Framework 1.3.0 or a compatible later 1.x release. Install this package and its dependencies in a Thunderstore-compatible **For The King** profile. Restart the game after installing or removing content. Use either this package or the same mod from the in-game marketplace, not both.

Paid DLC you do not own remains locked, hidden entries stay hidden, and temporary cloud entries follow what the game currently offers. See the [player guide](https://jarlbrak.github.io/ftk-mod-framework/mods/lore-store-unlocked/) for co-op and behavior limits.
