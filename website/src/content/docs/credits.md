## Original artwork

Paladin artwork by JarlBrak uses original generated concepts, Hyper3D Rodin models and atlases, and Blender fitting and export. Code and declarative data retain MIT licensing. Generated artwork has separate terms: read the [Paladin asset notice](../media/ASSET-LICENSE.md) and its linked terms before redistributing it.

The author confirmed the Creator plan was active during model generation on September 25, 2026. This is author confirmation, not provider verification. Generation provenance is not an independent guarantee of third-party rights clearance.

Library cards consistently use original promotional banners, not game captures. Paladin's banner is the illustration first published with 1.2.0, reused as class artwork for its current listing; it is not a literal preview of every 1.3.0 equipment model. The published Thief page uses its original promotional artwork. The Coming Soon Thief preview uses a new Nightblade illustration based on the current Cowl, Jack, Steps and Nightglass Twins models. Its pose, face and lighting are illustrative; it is not a gameplay capture. Possum uses a website edit of its published banner: the title typography and centered divider match the library, and the embedded version badge has been removed. The package artwork remains unchanged. Lore Store Unlocked uses its published 1.0.1 banner unedited: an image-generation illustration made from text prompts and edits of its own generated scene, with no game asset or screenshot supplied, and titled in the same typography as the other banners. It is promotional art, not a gameplay screenshot, and its prompt is kept with the package source. The equipment galleries use HTML tooltip cards with studio item artwork.

## Native game captures

Earlier Paladin gallery versions used the overhaul campaign's verified macOS captures. Original source hashes and capture scope are retained in the [release evidence record](https://github.com/jarlbrak/ftk-mod-framework/tree/master/docs/evidence/paladin-1.3.0). The website stores only compressed display derivatives and a curated source-hash manifest, not internal validation logs.

Native bodies, faces, hair, backpacks, UI, and shared weapon glyphs remain game-owned. Screenshots document the mod within the game; they do not make those underlying assets original framework artwork. No game assemblies or extracted native models or textures are distributed by this website.

## Item artwork

The 96 published equipment cards use original artwork projected from the hash-verified Paladin 1.4.0 and Thief 1.0.0 packages. Published icons are retained where available. The fourteen Paladin hammers use website studio stills rendered from their published models and atlases. These are labeled studio artwork, not game captures. Source and derivative hashes are retained with the site. No native item art is extracted or republished.

The separate Coming Soon previews contain 32 Blacksmith cards and 96 Paladin/Thief update cards. The update portraits are consistent studio renders of the candidate display meshes and delivered textures, with package, source and output hashes retained. They show unpublished equipment, including Thief pistols. These images do not establish equipped fit, native animation or release readiness.

## Archived studio films

Kingsfall and The Last Bastion turntables render the actual original model and texture from the hash-verified Paladin 1.3.0 package. Camera, lighting, and rotation are authored for the website. They are studio animation, not gameplay footage, a native attack animation, or proof of character fit. There is no audio. These older films are retained as media sources; current equipment galleries use static portraits.

The rendering script and source/output hashes are maintained with the website. Still images are resized to a maximum width of 1280 pixels and encoded as WebP; films use compressed MP4 and WebM with WebP posters. No generative edits were applied to native captures.
