Framework and mods have separate release numbers. This site documents **framework 1.5.1** (stable), **framework 1.6.0** (preview), **Paladin 1.4.0**, **Thief 1.0.0**, **Possum 1.0.0**, and **Lore Store Unlocked 1.0.1**. These are published downloads. No unreleased features are presented as available.

## Game and platform

Use the original For The King, not its sequel. Paladin, Thief, Possum, and Lore Store Unlocked are published for **Windows, macOS, and Linux**, using the same platform-neutral content archives. Native gameplay has been verified on macOS; Windows and Linux gameplay remain unverified. Platform availability does not remove the game-build check: the installed game must match a fingerprint declared by the package. An unrecognized Windows, macOS, or Linux build is still blocked.

## Skyharbor menu background

Framework 1.4.0 includes Skyharbor on the same framework download platforms. Its airship animation and front-end menu transitions were checked in a macOS game copy. Windows and Linux live behavior remains unverified. The scene is authored for 16:9; other aspect ratios remain unverified. The scene changes menu presentation only: Party Select retains the native character stage, and playable campaigns keep their existing world presentation. It does not add an airship campaign.

The background is enabled by default and can be [disabled in the configuration](../troubleshooting/#change-the-menu-background). Its local animation does not change character statistics, saves, or multiplayer content identities. Online co-op gameplay remains unverified.

## Tweaks (framework 1.6.0 preview)

[Tweaks](../tweaks/) are part of the framework download and need no mod. Tweaks marked **Only you** change your own display and controls. **Shared rules** tweaks are decided when a run starts, written into its saves, and restored on resume; a save made before 1.6.0 follows your current settings. In online co-op, Shared rules tweaks are off for everyone until a later release.

Windows and Linux gameplay are unverified; in-game checks so far were solo play in a macOS game copy. Whether the original game, without the framework, opens a save carrying the Shared rules record has not been checked. Controllers are not supported for refunding focus or one-press inventory.

## Saves and multiplayer

Online co-op is unverified. Matching versions and mod sets is necessary preparation, not proof of compatibility. Existing-save migration is not a promised feature. Restore a save's original mod set or begin a new run if you change content. Removing a mod does not modify the save to remove that dependency.

## Published versus preview

Published pages describe the immutable catalog packages named above. Future previews must carry a separate **Preview / not published** label and must never replace published stat tables. Selecting the launcher's Preview channel is a separate framework update choice; it is how you get framework 1.6.0. Keep it out of an ongoing run unless you intend to test that release.

## Thunderstore Windows tester preview

Bootstrap 1.0.0 was submitted to Thunderstore but rejected as Invalid submission, so it is not available through the mod manager. It targets native Windows x64 with .NET Framework 4.8. Framework 1.5.1 supplies its launcher handoff. Automated Windows launcher and installer checks pass, but no running-game handoff, mod activation, or update/relaunch acceptance has been performed. No specific mod manager is yet verified end to end. This preview does not establish Proton support or broaden the published game-build fingerprints.
