# FTK Mod Framework 1.3.0

Framework 1.3.0 adds a Lore Store unlock that data packages can declare with
`{"kind": "loreStoreUnlock", "id": "all"}`. While a package with this entry is
enabled, every Lore Store entry the player could buy reads as purchased. Entries
from free DLC packs also unlock. Entries for unowned paid DLC, entries the game
hides from the store, and cloud promotions it is not currently offering keep
their real state. A purchased class is also shown at character creation.

The unlock only changes the game's answer to purchase queries while the package
is loaded. It writes no Lore Store purchase to the player's profile or to Steam,
so removing the package restores the player's own purchases. Lore points earned
meanwhile remain the player's. The entry requires next-launch activation and
disables title-screen hot activation while it is active. Lore Store Unlocked
1.0.0 is the first package to use it. Existing compatible 1.x packages remain
supported, and framework 1.2.1 is included in the automatic upgrade range.

## Verification and limits

Release build, LoreStoreUnlock, HotReloadPackages, PlayerRaces, PlayerMods and
the other capability checks, installer fixtures, Go helper tests including the
new package validator rule, Unix launcher fixtures, release-manifest tests and
catalog validation pass. On macOS, an isolated game copy seeded with a real
profile showed every non-DLC and free-DLC Lore Store entry as owned with the
package and restored the original locks after removal. All Lore Store purchase
records were unchanged. The macOS Steam deployment loaded framework 1.3.0,
registered 113/113 enabled content entries with zero content errors or warnings,
and showed every store entry as owned. After restoring framework 1.2.1 without
the package, the real profile's statistic and achievement values matched a
backup taken before the test. The optional full diagnostic suite was off.

The verified game assembly remains
`94cab5f9be9633f7f85f6f072e0b5b919c605bbecb3414422f8f008d9b2bc1c8`.
An unbought entry from owned paid DLC could not be exercised because the tested
profile already owned every Lost Civilization entry. Unlocked items in shops and
loot during a run, Windows and Linux/Proton gameplay, and online co-op remain
unverified. Windows launcher availability remains a preview; Linux arm64 is
helper tooling, not a native ARM game port. macOS downloads are not notarized
and may require right-click > Open. Steam may need one restart to refresh
shortcut artwork.
