# FTK Mod Framework 0.1.0 early-access preview

Play For The King with the community mod framework through a branded Steam launcher.
This is an early-access preview. Co-op groups need matching mods and framework versions.

## Download and play

Download one archive from this release:

| Your computer | Download | Add this file as a non-Steam game |
| --- | --- | --- |
| Mac, Intel or Apple Silicon, macOS 13+ | `FTKModdedLauncher-macos-universal.zip` | `For The King Modded.app` |
| Linux x64 or Steam Deck | `FTKModdedLauncher-linux-amd64.tar.gz` | `For The King Modded.sh` |
| Windows 10/11 x64, .NET Framework 4.8 | `FTKModdedLauncher-windows-x64.zip` | `FtkModdedLauncher.exe` |

1. Install and own the original **For The King** on Steam.
2. Extract the archive to a permanent folder. Keep its files together.
3. In Steam, choose **Games > Add a Non-Steam Game > Browse**, then select the file above.
4. Name it **For The King Modded** and launch. On Windows, choose **Play** in the launcher.

First launch installs the bundled framework and matching BepInEx loader if needed.
An internet connection is needed for the initial loader download. Steam library artwork
is applied automatically, preserving any custom artwork. Restart Steam if it still shows
the old artwork. On macOS, a downloaded unsigned app may require right-click > Open.
First-time macOS/Linux setup may restart Steam to configure its launch option.

## Included

- A branded launcher with automatic Steam cover, banner, logo, and icon setup.
- A framework update check before every launcher Play. Compatible stable releases replace
  the framework and paired helper together, preserving mods, settings, and saves. Offline
  checks keep the verified installed version; interrupted installations recover before launch.
- An in-game Mods browser with installed content controls, a free community marketplace,
  preview images and galleries, and review of changes before applying them on restart.
- Bundled sample content including the Thief and Innkeeper classes and two adventures.
  Developer diagnostics and forced test encounters are disabled for players.

The community catalog initially contains no downloadable community submissions. More mods
will appear after packages are reviewed and published. The framework's support fixes run
as infrastructure rather than separate player-facing mods.

## Preview limits

macOS launch and game smoke have been tested. Windows is cross-built and checked with
installer fixtures, but Windows installation, SmartScreen, Steam integration, and gameplay
have not been tested on a Windows machine. Native Linux and Proton gameplay also need
real platform testing. The Linux arm64 archive is helper tooling support, not a native ARM
port of the game.

This preview is excluded from the stable automatic-update feed. The launcher will use
its bundled version until a newer compatible stable release is published. Automatic
updates currently allow only the verified game assembly fingerprint in the release policy;
other builds keep their working version. The updater does not replace BepInEx or the launcher
bootstrap. Launching the original Steam shortcut directly skips the launcher update check.

Non-Steam shortcuts show local artwork and a name; they do not gain an official Steam store
page or achievements. The framework and launcher contain no copyrighted game assemblies.
`SHA256SUMS` covers all release artifacts.
