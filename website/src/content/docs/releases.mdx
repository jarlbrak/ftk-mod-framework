## Framework 1.5.0

Adds default-on automatic bug reports. Detected errors and unexpected previous-session exits can send filtered diagnostics to a public framework GitHub issue without opening a prompt. Turn **Automatic bug reports** off in **Mods > Settings & Help** to stop new sends. The manual **Report Bugs** editor stays available when you want to add context. Automatic diagnostics may contain personal information from mod logs; read the [reporting disclosure](https://reporting-api-production-ff50.up.railway.app/privacy). A send already in progress may finish after the setting is turned off. [Download the 1.5.0 launcher](https://github.com/jarlbrak/ftk-mod-framework/releases/tag/v1.5.0).

## Framework 1.4.0

Introduces **Skyharbor**, an animated 3D fortress and airship dock for the menu background. The airship eases away from its berth, follows broad turns through the sky, and returns for a gentle docking approach. Propeller motion, mooring lines, and the gangway follow the departure and arrival sequence. The title adds **MODDED EDITION** beneath the original logo.

The scene stays behind front-end menus and dialogs, and the flight continues as you browse. Party Select keeps the native character stage. Skyharbor is menu scenery; this release does not add a playable sky campaign.

Skyharbor is included and enabled by default. [Restore the original menu background](../troubleshooting/#change-the-menu-background) through the framework configuration if preferred. Restart the game after updating. Download the launcher from the [framework 1.4.0 release](https://github.com/jarlbrak/ftk-mod-framework/releases/tag/v1.4.0).

The scene and its transitions were tested in a macOS game copy. Windows and Linux gameplay remain unverified. See [compatibility](../compatibility/#skyharbor-menu-background).

## Framework 1.3.0

Adds the Lore Store unlock used by [Lore Store Unlocked 1.0.0](../mods/lore-store-unlocked/). While a package declaring it is enabled, every Lore Store entry you could buy reads as purchased, including free DLC entries. Unowned paid DLC, entries the game hides from the store, and cloud promotions not currently offered keep their real state. No Lore Store purchase is written to your profile or Steam, so removing the package restores your own unlocks. Existing 1.x mods remain supported, and framework 1.2.1 is included in the launcher's automatic upgrade range. Restart the game after updating. Download the launcher from the [framework release](https://github.com/jarlbrak/ftk-mod-framework/releases/tag/v1.3.0).

## Framework 1.2.1

Restores native-style class selection for Paladin 1.4.0, with a two-sentence flavor description and short skill labels. Guard's detailed rules remain in its combat ability description. Use a full game restart after updating. Download the launcher from the [framework release](https://github.com/jarlbrak/ftk-mod-framework/releases/tag/v1.2.1). Framework and mod versions are independent; a new mod release does not replace the framework download.

## Paladin upgrade notes

Moving from 1.3.0 to 1.4.0 requires framework 1.2.1. New Paladins start with the Novice Hammer and Novice Aegis. Armor and trinkets must be acquired, and Smite requires an equipped Paladin trinket. Existing characters keep their equipment.

Class selection now shows **Skill: Guard** and **Passive Skill: Cleansing March** beneath two sentences of flavor. Base stats, ability mechanics, equipment values, and artwork are unchanged. Base Vitality remains 80; the Highward, Mercy, Censure, and Verdict great hammers retain damage values of 32, 34, 34, and 37.

Restart after preparing an upgrade and start a new adventure when changing content. Existing-save migration and long-campaign balance remain unverified. [Read the full Paladin guide](../mods/paladin/).
