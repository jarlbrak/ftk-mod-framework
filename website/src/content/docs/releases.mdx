## Framework 1.7.1

[Framework 1.7.1](https://github.com/jarlbrak/ftk-mod-framework/releases/tag/v1.7.1) adds a **Guarded** shield to the protected ally's native buff/debuff status row. Hovering it explains the active protection. The shield clears when Guard expires, its guardian is incapacitated, the protected ally is lost, or combat ends. This is a status display improvement; Guard's damage rules and the Paladin 2.0.0 package are unchanged. Download the [current launcher](../installation/) and restart after updating.

## Framework 1.7.0 and Paladin 2.0.0

[Framework 1.7.0](https://github.com/jarlbrak/ftk-mod-framework/releases/tag/v1.7.0) is available for Windows, macOS, and Linux. It includes the shared Equipment Exchange, material and equipment improvements, and the fixes and Tweaks introduced in 1.6.x. [Download the launcher](../installation/) and restart after updating.

[Paladin 2.0.0](https://github.com/jarlbrak/ftk-mod-framework/releases/tag/paladin-v2.0.0) requires framework 1.7.0 or a compatible later 1.x release.

- **Hammer-gated class actions.** Paladins gain Censure and Smite with an eligible hammer. Paladin hammers provide a single native Strike, so other classes can use them without gaining Paladin skills. Smite deals magic damage and has a perfect-only stun chance.
- **Three armor roles.** Matching Mercy armor strengthens healing and Smite; Verdict protects allies; Censure favors physical vengeance. Each role has explicit costs. Accessories do not substitute for matching armor.
- **One shared gear store.** Level-8-and-above encounters can award Guild Tokens. Exchange one token for a piece at a city's native Back Alley vendor. It shows class-relevant gear and hides pieces already owned; purchases have no refunds.
- **Revised equipment presentation.** Updated materials, helmet fit, weapon placement, item framing and studio media keep the six families visually consistent.

The token service is built into the framework and activates when a participating catalog is installed. No separate currency mod is required. [Read the Paladin guide](../mods/paladin/) for role bonuses, artifacts and acquisition.

## Framework 1.6.2 (preview)

[Framework 1.6.2](https://github.com/jarlbrak/ftk-mod-framework/releases/tag/v1.6.2) is a **preview** release that fixes two problems. It adds no new tweaks. At its publication, Stable remained on 1.5.1 and Preview offered 1.6.2. See the latest regular release above.

- **Automatic bug reports are delivered.** Before 1.6.2, automatic reports were saved in a folder the sending helper refuses, so none of them reached GitHub, and one stuck report blocked every later one. They now send, a failed report never holds up a newer one, and the game's own sound-engine error at startup is no longer reported. The first launch of 1.6.2 deletes the old, never-sent reports without sending them. If you want an earlier problem looked at, use **Options > Report Bugs**.
- **Saves with missing content are refused instead of hanging.** Resuming a save that uses an enemy, map encounter, item, class, quest or adventure that is not installed used to stop on "Crafting adventure". The game now shows **Can't load this save**, lists what is missing, and leaves the save file unchanged. This mostly affects saves made with a mod that has since been removed.

The save check was tested in solo play in a macOS game copy. Automatic delivery was checked with one unexpected-exit report sent from a macOS test copy. An automatic error report has not been sent live, and Windows and Linux delivery are untested. The known limitations of 1.6.0 and 1.6.1 still apply. See the [full list](../tweaks/#known-limitations).

**Known issue in the game itself:** on macOS the game can hang when you quit, inside the game's own sound engine. Force quit the game if it does not close.

## Framework 1.6.1 (preview)

[Framework 1.6.1](https://github.com/jarlbrak/ftk-mod-framework/releases/tag/v1.6.1) is a **preview** release that fixes two problems found in 1.6.0. It adds no new tweaks. At its publication, Stable remained on 1.5.1 and Preview offered 1.6.1. See the latest regular release above.

- **Refund focus key.** In 1.6.0 the refund key was **Backspace**, which is also the game's **End Turn** key, so pressing it ended your turn and the focus stayed spent. The default is now **F**. If your settings file still has Backspace, 1.6.1 changes it to F when the game starts. A key that one of the game's own controls uses never refunds, and the log warns once. The refund tooltip now also appears when you move the pointer onto a faded pip straight from the map.
- **Fewer false stuck-turn warnings.** The `STUCK-TURN` log line no longer appears while an encounter's Fight or Sneak menu waits for you, while a tutorial popup or the encyclopedia is open, or while a single-player game waits for your own game to be ready.

Both fixes were checked in solo play in a macOS game copy. The known limitations of 1.6.0 still apply: Windows and Linux gameplay are unverified, controllers are not supported for refunding focus or one-press inventory, and co-op with tweaks has not been played. See the [full list](../tweaks/#known-limitations).

**Known issue in the game itself:** on macOS the game can hang when you quit, inside the game's own sound engine. The framework is not involved. Force quit the game if it does not close.

## Framework 1.6.0 (preview)

[Framework 1.6.0](https://github.com/jarlbrak/ftk-mod-framework/releases/tag/v1.6.0) is a **preview** release. At its publication, Stable remained on 1.5.1 and Preview offered 1.6.0. See the latest regular release above.

It adds **Tweaks**, a new tab under **Mods > Tweaks** with optional fixes, extra information and conveniences for the base game. Fixes are on by default. Information and Convenience tweaks are off until you turn them on.

- **Fixes (on by default):** dungeon names in quest text, the Wet and group shield icons cleared after combat, Taunt and Petrified status icons with a Dazed tooltip, corrected Perfect chances, and a stuck skip-turn popup that closes itself. Two fixes change how a run plays and carry balance notes: Find Herb refreshes after each full turn cycle in a dungeon, and poison countdowns are kept when you load a save.
- **Information (off by default):** XP within the level, poison turns left, sell price in item details, encounters that vanish, and the achievements that easier House Rules disable.
- **Convenience (off by default):** skip intro, one-press inventory, and refunding focus spent on movement.

Shared rules tweaks are decided when a run starts, recorded in its saves, and restored when you resume it. Saves made before 1.6.0 follow your current settings. In online co-op, Shared rules tweaks are off until a later release. The framework also writes `STUCK-TURN` and `SOFTLOCK-SIGNATURE` lines to the log to help diagnose stalls, and bug report diagnostics now include your tweak settings. Read the [Tweaks guide](../tweaks/) for every tweak, its default and its balance note.

**Known limitations:** Windows and Linux gameplay are unverified; in-game checks so far were solo play in a macOS game copy. Controllers are not supported for refunding focus or one-press inventory. Still open in the game: whether the original game without the framework opens a save carrying the Shared rules record, a second Find Herb in the same dungeon, the group shield icon, Skip intro on Windows, controllers, and co-op. See the [full list](../tweaks/#known-limitations).

## Framework 1.5.1 and bootstrap 1.0.0

[Framework 1.5.1](https://github.com/jarlbrak/ftk-mod-framework/releases/tag/v1.5.1) adds the Windows launcher handoff for the independently versioned [bootstrap 1.0.0](https://github.com/jarlbrak/ftk-mod-framework/releases/tag/bootstrap-v1.0.0). The launcher waits for the original game to exit before installing, acknowledges startup, and preserves the durable entry in Start menu and Steam shortcuts. Existing pins, framework updates, and the mod marketplace keep their normal flow.

**Windows tester preview:** the complete in-game setup flow remains unverified. Automated launcher/helper and installer checks passed on Windows, macOS, and Ubuntu, and Unity-free CI passed. No new live-game smoke was performed. The Thunderstore upload completed through GitHub CI, but Thunderstore rejected the submission as **Invalid submission**. It is not available in the mod manager. Volunteers can use the regular [Windows launcher](../installation/) and report their results. A stable framework release does not imply verified Windows gameplay. Bootstrap 1.0.0 is only the thin initial installer; its number is independent of framework releases.

## Framework 1.5.0

Adds default-on automatic bug reports. Detected errors and unexpected previous-session exits can send filtered diagnostics to a public framework GitHub issue without opening a prompt. Turn **Automatic bug reports** off in **Mods > Settings & Help** to stop new sends. The manual **Report Bugs** editor stays available when you want to add context. Automatic diagnostics may contain personal information from mod logs; read the [reporting disclosure](https://reporting-api-production-ff50.up.railway.app/privacy). A send already in progress may finish after the setting is turned off. [Download the 1.5.0 launcher](https://github.com/jarlbrak/ftk-mod-framework/releases/tag/v1.5.0).

## Framework 1.4.0

Introduces **Skyharbor**, an animated 3D fortress and airship dock for the menu background. The airship eases away from its berth, follows broad turns through the sky, and returns for a gentle docking approach. Propeller motion, mooring lines, and the gangway follow the departure and arrival sequence. The title adds **MODDED EDITION** beneath the original logo.

The scene stays behind front-end menus and dialogs, and the flight continues as you browse. Party Select keeps the native character stage. Skyharbor is menu scenery; this release does not add a playable sky campaign.

Skyharbor is included and enabled by default. [Restore the original menu background](../troubleshooting/#change-the-menu-background) through the framework configuration if preferred. Restart the game after updating. Download the launcher from the [framework 1.4.0 release](https://github.com/jarlbrak/ftk-mod-framework/releases/tag/v1.4.0).

The scene and its transitions were tested in a macOS game copy. Windows and Linux gameplay remain unverified. See [compatibility](../compatibility/#skyharbor-menu-background).

## Framework 1.3.0

Adds the Lore Store unlock used by [Lore Store Unlocked](../mods/lore-store-unlocked/). While a package declaring it is enabled, every Lore Store entry you could buy reads as purchased, including free DLC entries. Unowned paid DLC, entries the game hides from the store, and cloud promotions not currently offered keep their real state. No Lore Store purchase is written to your profile or Steam, so removing the package restores your own unlocks. Existing 1.x mods remain supported, and framework 1.2.1 is included in the launcher's automatic upgrade range. Restart the game after updating. Download the launcher from the [framework release](https://github.com/jarlbrak/ftk-mod-framework/releases/tag/v1.3.0).

## Framework 1.2.1

Restores native-style class selection for Paladin 1.4.0, with a two-sentence flavor description and short skill labels. Guard's detailed rules remain in its combat ability description. Use a full game restart after updating. Download the launcher from the [framework release](https://github.com/jarlbrak/ftk-mod-framework/releases/tag/v1.2.1). Framework and mod versions are independent; a new mod release does not replace the framework download.

## Paladin upgrade notes

Update the framework to 1.7.0 before installing Paladin 2.0.0, then restart the game. New Paladins start with the Novice Hammer and Novice Aegis. Censure and Smite now follow the Paladin's class and equipped hammer; trinkets no longer grant spells. Final-tier gear is obtained through Guild Tokens and the Back Alley vendor.

Keep a run's framework and mod versions consistent. Start a new adventure when changing content. [Read the full Paladin guide](../mods/paladin/).
