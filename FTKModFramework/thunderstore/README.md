# FTK Mod Framework

Windows setup for FTK Mod Framework, a modding framework for the original **For The King**.

## Setup

1. Install this package with your mod manager and launch the modded game.
2. Choose **Set up and open FTK Modded Launcher**. Setup downloads the launcher from our GitHub releases. Once the game closes, choose **Play** in the launcher.
3. Use the launcher for future play and framework updates. Install content mods through the in-game **Mods** menu. **Add to Steam / Art** in the launcher can create a Steam shortcut.

Setup requires internet access and .NET Framework 4.8. The launcher and framework install outside the mod-manager profile; deleting the profile does not uninstall them.

**Windows testing:** the complete in-game setup flow has not been verified yet.
