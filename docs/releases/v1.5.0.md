# FTK Mod Framework 1.5.0

Framework 1.5.0 adds automatic bug reporting, enabled by default. When the game
detects an error or an unexpected previous-session exit, it can send filtered
diagnostics to a public issue in the FTK Mod Framework GitHub tracker without
opening a reporting prompt. Turn off **Automatic bug reports** in **Mods > Settings
& Help** to stop new automatic sends. The manual **Report Bugs** editor remains
available for reports that need a player's explanation.

Automatic reports contain a generated description, filtered recent game and
framework logs, versions, installed mods, and session context. They do not include
saves or screenshots. Filtering can miss personal information in mod logs. Read the
[reporting disclosure](https://reporting-api-production-ff50.up.railway.app/privacy)
before leaving automatic reports enabled. An in-progress send may finish after the
setting is turned off. Repeated error signatures are suppressed for 30 days, and a
failed automatic submission retries on a later launch for up to seven days.

The reporting service schema must be deployed before this framework release. The
launcher can update compatible 1.x installations in the published game-build range.
Use a full game restart after updating.

## Verification and limits

Game-free framework, reporting service, installer, launcher, release-manifest, and
website checks are recorded with the release. Live gameplay and Windows and
Linux/Proton gameplay coverage must be reported separately. Automatic issue delivery
is verified through the service's synthetic report procedure before client rollout.
macOS downloads are not notarized and may require right-click > Open. Steam may need
one restart to refresh shortcut artwork.
