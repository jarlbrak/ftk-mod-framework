# FTK Mod Framework 1.8.1

This patch fixes weapon tooltip presentation. Eligible Paladin hammers now show
two separate rows in the game's native skill color:

- `Paladin Skill: Censure`
- `Paladin Skill: Smite`

The framework derives these labels from registered class and weapon associations.
Native weapon actions, modifiers, combat behavior and class eligibility are
unchanged. Paladin remains version 2.0.1; no new mod package is required.

The public Paladin guide now follows the in-game weapon tooltip's wording and
order, including set and artifact perk text. Roll symbols appear above the item
name, and Artifact hammer cards use the native red theme. The website uses
original artwork and browser substitutes for native fonts and icons, with the
set preview showing no matching armor or armament equipped.

## Updating

Compatible Stable-channel launchers receive framework 1.8.1 before the next Play.
Fully close and restart the game to load the new framework. Existing pins remain
unchanged. Fresh installations can use the platform launcher archives attached
to this release.

## Verification and limits

All 14 Paladin hammer tooltips were inspected in a disposable macOS game copy.
Each displayed both skill labels once. The front, modifier, skill, perk and set
rows matched the website text in the same unequipped set context. Representative
common, rare and Artifact cards were visually reviewed for spacing and clipping.
Weapons were supplied through a test-only starting-inventory fixture; this does
not establish ordinary acquisition.

The focused CombatProficiencies suite passed 116 checks. The framework Release
build and the desktop/mobile website checks passed. Release packaging, broader
game-free validation and public delivery are recorded in the
[validation record](v1.8.1-validation.md).

No new Windows, Linux/Proton, co-op, save lifecycle or gameplay balance claim is
made by this presentation fix.
