# Historical Thief fitting review (rejected art)

These historical captures show rejected apparel geometry. Current redesign evidence is recorded separately in `../redesign-review/README.md`.

These are captures of the actual native male Thief avatar using the Treasure Hunter class chassis, with original Thief equipment installed in an isolated single-player game. Studio views preserve the native idle pose and use bone-based camera framing. They are not concept images or offline mannequin renders.

The Street outfit uses the authored starting loadout. The Nightblade outfit and Skeleton Key use a disposable starting-item fixture. No item grants or stat changes were used for the fit review.

## Historical corrections

- Translate equipped headwear down 0.55 units into the native crown mount. The original hood floated entirely above the head.
- Extend the hood back and sides around the native rear skull. The initial mount correction exposed clipping visible only from behind.
- Add a continuous trouser pelvis to join the waist and leg tubes.
- Keep sleeve cross sections on a stable axis at the shoulder and align cuffs with the forearm.

`nightblade-male-before-*` retains the rejected original fitting. `nightblade-male-front.png`, `nightblade-male-three-quarter.png` and `nightblade-male-back.png` show the superseded male idle fit after the rear-clearance correction. The user rejected this art; it is not accepted visual quality. `street-male-*` shows the revised starting outfit in front, three-quarter and back studio views plus native combat idle. The combat screenshot shows the reduced menu: basic Strike, Feint and Slip Away, alongside native Flee.

Exact capture IDs, image hashes and loaded Core binary hashes are recorded in `../ranged-apparel/native-fit-review.json`. Source and packaged model hashes are recorded by the art manifest and package provenance.

## Remaining gates

Female and alternate race fitting, the other progression tiers, attack and hit animation clipping, bow draw/string behavior, equipment rebuilds, and loot displays need their own native observations. Native material tint warms the authored palette, particularly the Street coat and blue patch; exact palette fidelity is not claimed.
